Expense Tracker App

A responsive Expense Tracker application built using React that helps users manage daily expenses efficiently.
This project demonstrates the use of important React Hooks and modern frontend best practices.

🚀 Features

* Responsive and user-friendly UI

* Add, view, and manage expenses easily

* Form input handling with React state

* Data fetching from a mock API

* Optimized performance using React hooks

🛠️ Technologies Used

* React JS

* JavaScript (ES6+)

* HTML5 & CSS3

* React Hooks

📚 React Hooks Implemented
1. useState

* Used to manage form inputs and expense data dynamically.

2. useEffect

* Fetches and displays expense data from a mock API when the component loads.

3. useRef

* Manages form field focus for better user experience.

4. useMemo

* Optimizes calculations and prevents unnecessary re-renders.

5. useCallback

* Memoizes functions to improve overall application performance.

📱 Responsiveness

The application is fully responsive and works smoothly on:

* Desktop

* Tablet

* Mobile devices

🎯 Purpose of the Project

* This project was created to:

* Practice React Hooks in a real-world application

* Improve state management and performance optimization skills

Build a clean and responsive frontend UI

📂 How to Run the Project
# Install dependencies
npm install

# Start development server
npm start / npm run dev


The app will run locally at:

http://localhost:3000
